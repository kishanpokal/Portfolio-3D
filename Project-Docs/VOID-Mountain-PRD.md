# V.O.I.D Mountain Interactive Portfolio — Product Requirements Document (PRD)

## 1. Project Overview

**Product Name:** V.O.I.D Mountain Interactive Portfolio

**Goal:** Create a high-performance, memorable 3D web portfolio that immediately demonstrates senior-level technical capability and creative vision while maintaining frictionless access to standard professional information.

## 2. Target Audience & User Personas

**The Hiring Manager / Recruiter**
Highly time-constrained. Needs to see the resume and contact information in less than 5 seconds. Will utilize the 2D "Fast Travel" UI.

**The Engineering Lead / Peer**
Looking for technical depth, frame-rate optimization, and code quality. Will actively explore the 3D environment to test the interactions.

## 3. Core Features & User Flow

**The Overworld (Mountain Trail)**
A linear 3D path with 4 specific checkpoints. Acts as the main navigation hub.

**Pocket Dimensions (Void Islands)**
Three distinct teleportation zones hidden inside stone statues on the mountain. These house the heavy information (About, Journey, Projects) to keep the main mountain visually clean.

**Safety Net UI (Fast Travel)**
A persistent 2D HTML overlay on top of the 3D canvas that allows instant teleportation to any zone, plus a permanent "Download Resume" button.

**High-Fidelity Project Demos**
The third Void Island must feature 3D smartphone models capable of natively playing vertical animation prompts and distinct video variants (e.g., specific demographic targeting like student vs. employed professional campaigns) for applications like TrackEasy.
